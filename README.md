# rocker-saver

Скрипт для автоматического сохранения истории сообщений из Rocket.Chat в GitHub-репозиторий в формате Markdown.

## Что делает

- Выгружает сообщения из указанных каналов и приватных групп
- Выгружает личные переписки (DM)
- Разворачивает треды в виде раскрывающихся блоков `<details>`
- Пропускает системные сообщения (вход/выход участников и т.п.)
- При повторном запуске забирает только новые сообщения (инкрементальное обновление)
- Коммитит изменения и пушит в GitHub-репозиторий

## Установка

Требуется Node.js 18+.

## Конфигурация

Скопируйте `config.example.json` и заполните:

```json
{
    "baseUrl": "https://my-rc.com",
    "repo": "https://github.com/user/rocket-chat-history.git",
    "channels": ["general", "random"],
    "historyDays": 365,
    "dmLimit": 100
}
```

| Поле | Описание |
|------|----------|
| `baseUrl` | URL вашего Rocket.Chat |
| `repo` | GitHub-репозиторий для хранения истории |
| `channels` | Список каналов/групп для выгрузки |
| `historyDays` | Глубина истории в днях |
| `dmLimit` | Количество DM-диалогов для выгрузки (0 — отключить) |

## Переменные окружения

```bash
export RC_TOKEN=<токен Rocket.Chat>
export RC_USER_ID=<ID пользователя Rocket.Chat>
export GH_TOKEN=<GitHub Personal Access Token>
```

Токен и ID Rocket.Chat можно найти в куках.

GitHub-токен должен иметь права `repo` для записи в репозиторий.

## Запуск

```bash
node index.js config.json
```

## Формат хранения

Каждый канал сохраняется в отдельный `.md`-файл (`general.md`, `dm-username.md` и т.д.). Каждое сообщение содержит метаданные в code-блоке:

```
​```
date: 2024-01-15T10:30:00.000Z
author: john.doe
msgId: abc123
​```
Текст сообщения
```

Треды отображаются свёрнутым блоком под родительским сообщением.
